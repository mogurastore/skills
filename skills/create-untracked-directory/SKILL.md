# Create Untracked Directory

ユーザーから受け取ったディレクトリ名で新規ディレクトリを作り、中身を git 管理から除外する。

## 手順

1. ディレクトリ名を特定する。
   - ユーザー指定がなければ、名前を1つ聞いて止める。推測で決めない。
   - 空文字、空白のみ、`-`始まりは受け付けない。聞き直す。

2. 作成先を確定する。
   - 既定はカレントディレクトリ直下の `<dirname>`。
   - サブパス指定 (`a/b` など) はそのまま使う。絶対パスや `..` を含む場合は実行前にフルパスを提示し、合意を取る。

3. 既存チェックをする。
   - 同名のファイルまたはディレクトリが存在すれば作成せず、別名を聞く。上書きしない。

4. ディレクトリと `.gitignore` を作成する。
   - `mkdir -p "<dirname>"` を実行する。
   - `"<dirname>/.gitignore"` に以下だけを書く:
   ```gitignore
   /*
   ```

5. 結果を報告する。
   - 作成したパスと `.gitignore` の内容を示す。
   - `git status --short` で当該ディレクトリの中身が出ないことを確認し、結果を伝える。
